Die Wassermeisterei ist ein Bodenfeuchtesensoren-Netzwerk im Citizen Science Ansatz.
Wir messen den prozentualen Wassergehalte im Boden mit digitalen FDR Sonden (SN300 SR No1 und SMT100). 
Die Daten werden via Modbus an LoRaWAN Funkmodule (Dragino RS485) und werden auf wasserkarte.org veröffentlicht.
