Bodenfechte messen - Daten mit LoRaWAN messen 
----------------------------------------
Wassermeistereiist ein Bodenfeuchtesensoren-Netzwerk im Citizen Science Ansatz.
Wir messen den prozentualen Wassergehalte im Boden mit digitalen FDR Sonden (SN300 SR No1 und SMT100). 
Die Daten werden via Modbus an LoRaWAN Funkmodule (Dragino RS485) gesendet, via LoRaWAN (ttn) übvübertragen und werden auf wasserkarte.org veröffentlicht. 
Mehr zum Projekt auf wassermeisterei.org 

Wassermeister is a citizen science project measuring soil moisture in Germany.
